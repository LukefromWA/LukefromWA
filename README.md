# Hey, I'm Lucas 👋

I'm a biologist first.

I've wanted to be one since I was nine years old. Mathematics found me later through an ecology modeling project, and now I spend most of my time somewhere between biology, mathematics, and computation.

I'm interested in computational genomics, mathematical epidemiology, scientific machine learning, and dynamical systems. My long-term goal is to build mathematically grounded, interpretable methods for studying biological systems.

## Current Projects

- 🦠 **Bayesian Stochastic Epidemiology** — Bayesian and stochastic epidemic models with an emphasis on mechanistic inference and uncertainty quantification.
- 📈 **Epidemiological Time Series** — Time series methods for infectious disease data, including forecasting, decomposition, and spectral analysis.

## Philosophy

I like understanding *why* something works before I use it.

That usually means reading the math, implementing it from scratch, testing it against established libraries, and only then applying it to real biological problems.
